A penalized spline estimator for functional linear 
regression with functional response
Jean Steve Tamo Tchomgui1,2 · Julien Jacques1
 · Guillaume Fraysse2 · 
Vincent Barriac2 · Stéphane Chretien1
Abstract
In many scientific studies in recent years, data have been collected at such a high 
frequency that they can be considered as functional data. In the case when both the 
response variable to be predicted and the covariates are functions, we provide a 
novel and easy-to-implement method addressing function-on-function linear model­
ling and obtain interpretable parameters. Two main types of models are considered: 
(i) the concurrent model which explains the response curve inline-eq-IEq1 at time t from the 
values at same time t of the covariates in
line-eq-IEq2; (ii) the (feed-forward) integral model 
which explains inline-eq-IEq3 based on the values of covariate curves in
line-eq-IEq4 observed at 
any times i n line-eq-IEq5. A regularized inference approach is proposed, which accurately 
selects an appropriate set of basis functions that can be used for functional data 
reconstruction and at the same time provides smooth and interpretable functional 
parameters. A functional confidence interval procedure is also proposed which uses 
the conformalization framework. Numerical studies on simulated data with different 
scenarios illustrate the good performance of our method to capture the relationship 
between covariates and response. The method is finally applied to well-known data 
and compared to a baseline: on Canadian weather data (predicting precipitations 
from temperature measurements) and on Hawaii ocean data (predicting ocean sa­
linity from temperature, oxygen, chloropigments and density measurements). Our 
method shows significant improvements on prediction error.
Keywords  Functional data analysis · Function-on-function regression · Penalized 
splines · Conformal prediction

1  Introduction
Most of the machine learning problems encountered in various fields of applied sci­
ences, including economics, finance, geosciences, or medicine ..., involve data that are 
no longer collected in a scalar form, i.e., a response i n line-eq-IEq6 described by a finite number 
of covariates. i n line - e q - IEq 7
. We instead observe several recordings (over 
time), sometimes for both the response, i n l i ne-eq-IEq8, and the covariates i n l i ne-eq-IEq9. 
As a result, new tools are needed to process and analyze this very fast growing resource 
of data. A quite natural idea that has emerged lately is to extend classical tools from 
data analysis to a new paradigm called Functional Data Analysis (FDA). This new 
paradigm has proven very successful at addressing the statistical analysis of data where 
at least one of the variables of interest needs to be processed as a function. Extension of 
linear regression to the functional setting has therefore naturally become a major area 
of research in FDA. While the literature is too vast to report here, references such as 
Ramsay and Silverman (2005), Ramsay et al. (2009), Horváth and Kokoszka (2012) 
and Kokoszka and Reimherr (2017) provide excellent introductions to FDA. Moreover 
Goldsmith et al. (2011) and Morris (2014) provide a broad overview of the methods of 
functional linear regression. As far as functional setting is concerned, different types of 
functional linear regression have been considered, depending on the functional nature 
of the response and/or at least one of the covariates. Thus, using the convention that 
first term denotes response-type and second term denotes covariate-type, all the fol­
lowing regression models are possible options to consider: function-on-scalar, scalar-
on-function and function-on-function. The scalar-on-function linear regression models 
are the most thoroughly studied ones in the current literature. Some references include 
Cardot et al. (1999) and Hastie and Tibshirani (1993).
Most of the inference approaches for these models rely on a basis expansion 
assumption. For instance Besse and Cardot (1996) and Ramsay and Silverman (2005) 
proposed spline-type approximations of the functional covariates and then performed 
the estimation step by minimizing a least squares criterion. Among other useful refer­
ences, Antoch et al. (2010) uses B-spline expansions for both the functional param­
eters and the functional covariates. The issue of possible non-identifiability was 
pursued in Scheipl and Greven (2016). In theses approaches, the functional regres­
sion models become equivalent to multivariate models on the basis expansion coef­
ficients. An alternative way is to consider Functional Principal Components Analysis 
(FPCA, Ramsay and Silverman (2005)), possibly using smoothness promoting penal­
ization (Silverman 1996; Besse et al. 1997). Appropriately determining the number 
of components is still an active area of research. Indeed, it was shown in Crainiceanu 
et al. (2009) that the shape of the functional parameters can drastically change as 
one or two additional principal components are included, making the process quite 
unstable and relatively difficult to interpret.
In comparison with scalar-on-function problems, function-on-function models, as 
addressed here, have been much less studied in the literature. For instance, Ivanescu 
et al. (2015) proposes, via the pffr method (penalized flexible functional regression), 
to estimate a function-on-function regression model using a penalized mixed model. 
In this setting as well, the main issue faced is not only the problem of accurately 
selecting the number of basis functions and the location of the knots (Li and Ruppert

In this paper, we firstly develop an efficient approach named PenFFR (i.e. FFR for 
the non penalized version) to estimate the functional parameters inline-eq-IEq28 of the concur­

We propose a penalized estimator of the corresponding functional basis coefficients. 
As shown below, our approach allows to simply choose equispaced knots and a suf­
ficient number of basis functions to capture the main features of the covariates. Over­
fitting is naturally avoided by penalizing roughness via controlling (maximizing) the 
second derivatives of the functional parameters. Rather than using LASSO penalties, 
like the FLiRTI method of James et al. (2009) or S-LASSO estimator of Centofanti

Ridge-type penalty, as in Manrique et al. (2018), but only on second derivative to 
ensure local linear relation between covariates and response. Another reason is moti­
vated by the lack of exact sparsity observed in real problems.
Secondly, we propose a method to build confidence intervals of the predictions 
given by the method. To achieve this, we draw a functional quantile regression by 
perturbing the standard linear regression and compute functional quantiles by optimal 
transport. This functional quantile regression is then combined with the conformal­
ized method to build a functional conformalized quantiles regression. Indeed, con­
fidence intervals are one way to guarantee how good the predictions are. They also 
help to assess statistical significance, model validation or decision making.  That is 
why in some practical situations the final inference goal is generally the estimation of 
a confidence interval of the predictions. To build confidence intervals with desirable 
properties such as distribution-freeness or non-asymptoticity, conformal prediction 
is paramount in modern machine-learning for providing reliable measures of predic­
tion uncertainty. A comprehensive development of this topic is originally presented 
in Vovk et al. (2005) and Lei et al. (2016). Angelopoulos and Bates (2023) propose a 
comprehensive overview, Tibshirani et al. (2019) present a weighted version which 
can be used for problems where the test and training covariate distributions differ.
Outline of the paper The paper is organized as follows: Sect. 2 shows how, under the 
assumption of functional basis expansion, the concurrent and integral models are trans­
formed into mixed matrix models. Section 3 details a two-step estimation scheme. The 
first step recovers the functional nature of the covariates, by approximating them into 
a functional basis. The second one computes the penalized estimation of the functional 
regression coefficients, which are themselves decomposed into another functional 
basis. Section 4 develops the functional quantile regression model by perturbing linear 
regression in order to provide conformal predictions. Section 5 contains a simulation-
based exploration of the method and confirms the efficiency of the proposed approach. 
Section 6 presents an illustration of the method on two real data sets. The first one is the 
well-known Canadian weather data set, in which the goal is to explain precipitation as 
a function of temperatures in different Canadian cities. The second one is the Hawaii 
ocean data set in which salinity is explained as a function of four functional covariates. 
Finally, Sect. 7 concludes the paper and presents some future work.

2  Linear models for function-on-function regression
This section shows how the functional models (1) and (2) can be, under the basis 
expansion assumption of covariates and parameters, reduced to a linear mixed model 
onto the discrete observations of the functional response and functional covariates.
2.1  Functional concurrent model
Linear regression for a functional response involving one or more functional covari­
ates in the concurrent model is a well-known problem. The main issue is to estimate an 
infinite dimensional parameter inline-eq-IEq30 through a finite sample of observations. As shown 
in Hastie and Tibshirani (1993), the interest of Model (1), also called the varying coef­
ficient model, is that any functional model can be theoretically reduced to this form. 
Chapter 14 in Ramsay and Silverman (2005) describes how this model can be fitted by 
minimizing an unweighted least squares criterion. The method proposed in this paper 
addresses the estimation problem using a penalized function-on-function regression as 
proposed in Ivanescu et al. (2015), where the problem is represented as a mixed model. 
Nevertheless, our work differs by the choice of the penalization criterion enforced on 
the functional parameter. The parameter inline-eq-IEq31 is expanded in functional basis using inline-eq-IEq32 
basis functions to get back to a classical mixed model for which the estimations of 
the parameters are well known. Furthermore, we allow to choose the number of basis 
functions inline-eq-IEq33 to be large enough to capture any desired variation of inline-eq-IEq34, and we add a 
roughness penalty term to get a smooth solution for the parameter at the end. As a first 
step of our modelling, we recover the underlying functional process, by using penalized 
cubic B-splines expansion for all the functional covariates.

3  B-spline-based penalized estimator
In both the concurrent and the integral models presented in Sects. 2.1 and 2.2 respec­
tively, we have used the decomposition of the infinite-dimensional functional covari­
ates and parameters into a truncated functional basis depending on the chosen number 
of basis functions. Such a number naturally needed to be correctly selected in order 
to avoid over- or under-fitting. Nevertheless, precise adjustment often induces a high 
computational effort. In the case of the B-spline basis, even more parameters have to 
be properly tuned such as the choice of the spline order and the location of the knots. 
In order to reduce the expected cost of such a computationally demanding procedure, 
we made the choice of a sufficiently large a priori value for inline-eq-IEq86 (or inline-eq-IEq87) and then apply a 
roughness penalty. This approach brings the benefit of reducing the overall computa­
tional cost, and of possibly improving the interpretability of the estimated functional 
coefficients. This last point is very interesting in the case of the linear model because 
as we already know, the interpretation of the relationship between the predictors and 
the response becomes more difficult when the shape of the functional parameter inline-eq-IEq88 (or 
inline-eq-IEq89) does not have a simple structure.
Various approaches to regularize the parameter shape have been proposed in the 
literature. In our setting of interest, the main idea is to enhance the model perfor­
mance and interpretability by adding a roughness penalty. The work of Leurgans et al. 
(1993) is among the first ones to explore the functional penalization and shows that 
the obtained estimator inline-eq-IEq90 (resp. inlin e-eq-IEq91) becomes less sensitive to the rather subjec­
tive choice of the number of basis functions inline-eq-IEq92 (resp. inline-eq-IEq93). More recently, James et al. 
(2009) proposed a method called Functional Linear Regression That is Interpretable 
(FLiRTI) which addresses the issue of choosing relevant penalties. Based on variable 
selection ideas such as the LASSO penalty, it produces accurate, flexible and highly 
interpretable estimates of the functional parameters. The main idea here is, instead 
of enforcing sparsity on the function themselves, to enforce sparsity of the deriva­
tives. Using the notation inline-eq-IEq94 for the inline-eq-IEq95 derivative of inline-eq-IEq96, it may be deduced that 
inline- e q-IEq97 guarantees that inline-eq-IEq98 has no effect on inline-eq-IEq99 at time t; inline- eq-IEq10
0 implies 
that inline-eq-IEq101 is constant at time t; inline- e q-IEq102 means that inline-eq-IEq103 is linear at time t, and so on 
for upper derivatives. The FLiRTI approach also combines sparsity enforcing penal­
ties for more than one derivative at a time, which can be useful for smooth parameters 
that may even vanish on some intervals.
Instead of the LASSO penalty applied in the FLiRTI method, where choosing the 
derivatives remains a difficult computational issue, our approach uses a Ridge pen­
alty on the second derivative of the functional parameters. The choice of penalizing 
the second derivative is mainly motivated by the desire to obtain a possibly locally 
linear relationship if needed. Moreover, the use of the Ridge penalty is motivated by 
the lack of exact sparsity observed in real problems and the clear benefits of getting a 
closed form formula for the estimators.

4  Conformal prediction
Conformal prediction (Vovk et al. 2005) is a framework that provides valid mea­
sures of confidence for individual predictions. It aims to quantify the uncertainty 
associated with predictions made by machine learning models, allowing users to 
assess the reliability of the model’s predictions. The key idea of this method is 
the construction of prediction regions around individual predictions to make sure 
that, with a certain level of confidence, the true value of the response falls within 
these regions. The resulting interval has desirable properties such as distribution 
freeness and non-asymptoticity. Despite these, classical conformal methods lead to 
intervals of constant or hardly varying length across the input space. Romano et al. 
(2019) proposed a fully adaptive method to heteroscedasticity named Conformal­
ized Quantile Regression (CQR) that combines conformal prediction to quantile 
regression inheriting advantages of both methods. We decided to adapt the CQR 
method to function-on-function regression.

4.2  Multivariate quantiles
Multivariate quantiles extend the concept of univariate quantiles to multivariate data,

But unlike in the 1-dimensional space inline-eq-IEq174, the d-dimensional space inline-eq-IEq175 (with i n line-eq-IEq176) is

4.3  Quantile function-on-function regression by perturbation
Quantile regression introduced by Koenker and Bassett (1978) offers a convincing 
solution by estimating conditional quantiles, which provide a more complete under­
standing of the distribution of the response variable. In FDA, the main difficulty relies 
on the fact that it is hard to design an equivalent to the pinball loss for functional 
output variables. In the scalar-on-function setup, we can mention works from Fer­
raty et al. (2005) and Cardot et al. (2005) which estimate conditional quantiles using 
non-parametric estimation and spline estimators respectively. For function-on-scalar 
and function-on-function setups, Liu et al. (2020) proposed a Bayesian framework by 
developing a scalable Gibbs sampler for an asymmetric Laplace likelihood distribu­
tion for the functional basis coefficients. Beyaztas et al. (2024) designed a pointwise 
pinball loss and a quadratic roughness penalty to estimate the model. Rather than 
using these techniques, we propose to use an alternative technique which does not 
require the assumption of continuity.
We developed a function-on-function quantile regression by perturbing linear 
function-on-function regression repeatedly. As done by any resampling methods such 
as bootstrap or jacknife, we generate artificial samples of predictions of the linear 
regression. The resulting quantile regression is simply the multivariate quantiles of 
those perturbing predictions. Originally, the use of perturbation in statistics can be 
found at least back in Gauss (1809), who used them to linearize a non linear problem. 
Later Stewart (1990)’s work examined the application of matrix perturbation theory 
for solving least squares regression problems, when the design matrix is contaminated 
by random errors. Our work is mostly inspired by Minnier et al. (2011), in which an 
interesting innovative and robust perturbation approach for regularized regression 
estimation is proposed and is particularly useful for high dimensional data. The idea 
of the method is to create series of perturbed datasets using them to estimate the vari­
ability of the regression coefficients. Specifically, for a given dataset each term in the 
log-likelihood for the PenFFR algorithm for any models (1) or (2), is multiplicatively 
weighted using i.i.d. exponential random variables with unit variance. Sampling this 
multiplicative weights several times with the same i.i.d. exponential distribution, we 
obtain independent realizations of the estimator of the functional prediction prob­
lem. These estimators then provide several independent functional responses inli

6  Application to real data
In this section, we apply the proposed methodologies for function-on-function regres­
sion (FFR and PenFFR) for concurrent and integral models. These models are applied 
to two well-known data sets in the FDA research community: Canadian Weather 
(CW) data available in the R package fda and Hawai Ocean (HO) data available in 
the R package FRegSigComp. We compare the prediction accuracy obtained using 
the proposed method with the accuracy obtained with other existing methods: (i) 
integral and concurrent Penalized Function-on-Function Regression (pffr, Ivanescu 
et al. (2015)) implemented in the R package refund; (ii) the signal compression 
approach (wSigcomp) designed by Luo et al. (2016) for the integral model and imple­
mented in the R packages FRegSigComp; (iii) the Optimal Penalized Function-on-
Function Regression (OPFFR) for the integral model (Sun et al. 2018), the Functional 
Principal Component Analysis (FPCA) and Functional Data Analysis method (FDA) 
also for the integral model (Ramsay and Silverman 2005). Due to the unavailability 
of code for the OPFFR approach, we simply use the published results as presented in 
(Sun et al. 2018).
Hyper-parameter tuning
For our methods (FFR and PenFFR), we consider cubic B-splines basis functions 
for both functional predictors and regression coefficients. On the CW data set, we use 
100 basis functions to address the functional and complex nature of the predictors 
and on HO data set we use 40 basis functions. This choice is motivated by the fact 
that on the raw data, predictors on CW data set have 365 measurements while predic­
tors in the HO data set have only 200 measurements. The number of basis functions 
of parameters is set to 40 for the concurrent model and 10 for the integral model on 
CW data. For the HO data, knowing that there are 4 functional predictors and that 
the number of features of design matrix depends on the square of the number of 
basis functions in the integral model, we choose 20 basis functions for the concurrent 
model and only 6 for the integral model. The penalty parameters inline-eq-IEq343 of any predictor 
are then selected using cross-validation on a predefined grid of values (10 equispaced 
values between 0.1 and 2.0).
For the pffr method, we used the default settings prescribed by the software and 
only set the number of basis functions for both the functional parameters and predic­
tors. To correctly compare to our proposed method, we also used a cubic splines basis 
for both the functional predictors and parameters for the two (CW and HO) data sets, 
as well as the same number of basis functions to recover the functional nature of the 
predictors and on parameters as in our method.
For the wSigcomp method designed for the integral model, the default settings of 
the software are also used. For the HO data set, tested by authors in their package 
description, the number of basis functions is set to 40 for the functional parameters 
and 20 for predictors. For the CW data, we slightly changed, but in the same propor­
tions, these value and set the number of basis functions involved for the functional

7  Conclusion
In this article, we have presented a new estimation process for the linear regression 
model with functional responses and functional covariates. We address the problem 
via expanding the functions onto a common B-spline basis, hence allowing the reduc­
tion of the functional model to a linear mixed model. Adaptation to unknown smooth­
ness is performed by adding a roughness penalty on second derivatives. Unlike any 
estimator based on basis functions, our estimates have a smooth shape and suffi­
cient flexibility to capture the encountered variability in various experiments with 
real-world data sets. We also design a framework for producing confidence interval 
bands for functional predictions. The method draws a functional quantile regres­
